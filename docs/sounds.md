# Sound generation

The 16 SFX files in `public/audio` are generated by [Earshot](https://github.com/Leonxlnx/earshot), version 0.3.0, upstream revision `925ebe56a1b755e5d354ab642bb8f344440cfa9c`. The sound IDs, durations, and peaks are recorded in `public/audio/provenance.json`. All selected entries are forge/pluck synthesis recipes, rather than fits derived from external recordings. Earshot's MIT license is included in `public/licenses/earshot-MIT.txt`.

To reproduce them with Python 3.10+:

```sh
git clone https://github.com/Leonxlnx/earshot.git /tmp/earshot
git -C /tmp/earshot checkout 925ebe56a1b755e5d354ab642bb8f344440cfa9c
python3 -m venv .venv
.venv/bin/python -m pip install numpy scipy soundfile
PYTHONPATH=/tmp/earshot .venv/bin/python scripts/render-earshot.py
```

The renderer uses the bank API with model checks disabled. No PyTorch, downloaded models, API key, or reference recordings are needed. The committed WAVs mean Python is unnecessary to build, deploy, or use the app.

The other six instruments are original deterministic synthesis in `public/synth.js`: 16 drum voices, additive struck-string piano, FM electric piano, drawbar-style organ, a band-limited detuned additive synth, and plucked kalimba. These are synthesized approximations rather than sampled acoustic instruments. Pitched pads span MIDI 24–119; tuning settings remap the visible note layout. Pads are one-shot voices with natural decay, and multiple pads can sound at once.
